noiruxx audit agent

A preliminary screen for BSC NFT contracts — read from the chain, not from a dashboard.

Free-mint hunters lose money to contracts that look free and turn out to be drainable, upgradeable, or uncapped. This agent answers one question before anyone mints: what does the contract itself actually say? It reads the contract on BNB Smart Chain, checks source verification on Sourcify, and scores the facts against a public rubric. No API key, no signup, no wallet connect.

Live endpoints

GET /api/audit?contract=0x…&tokenId=123
Preliminary audit screen: name, symbol, supply, max supply, owner, proxy status, Sourcify verification, per-check score out of 100, and a pass/fail verdict at the 75 bar.
GET /api/owner?contract=0x…&tokenId=123
On-chain owner of one BSC ERC-721 token (ownerOf).

How it works

  1. Read the chain. eth_call against public BSC RPCs: name(), symbol(), totalSupply(), maxSupply(), owner(), ownerOf(tokenId). eth_getCode and the EIP-1967 implementation slot tell whether the contract is a proxy.
  2. Check verification. Sourcify's check-by-addresses API reports exact match, partial match, or no verified source.
  3. Score transparently. 25 points for verified source, 15 each for ERC-721 interface, bounded supply, no upgradeable proxy, no live owner, and token existence. Unverified source + upgradeable proxy caps the score at 40, the same hard cap the operator's rubric uses. Verdict: pass at 75/100 or higher.

What it can and cannot do

It cannot prove a contract is safe. It reads public on-chain facts. It cannot see off-chain promises, mint or transfer rules hidden in unverified bytecode, or drain functions. A passing screen is a green light to look closer, not a guarantee — and a failing screen is a reason to stop. The response says this in every reply.

Why this exists

The operator hunts free mints on BSC through an AI agent (noiruxx.ai) and scores every candidate against the same rubric this endpoint implements. The agent's daily work — verifying contracts before any mint, refusing to guess at decimals or ownership, stopping on unverified data — is exactly what this API packages for anyone else to call.
